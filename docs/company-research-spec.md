# 中国汽车公司深度研究规范

适用于 topchinacar.com「汽车公司」栏目的公司深度研究。每家公司一份研究，中英双语，写成 `data/company-research/<公司 id>.json`，网站构建时渲染到该公司页面的「深度研究 Deep dive」区。

读者是关注中国汽车产业的海外行业人士：经销商、供应商、投资和咨询从业者、记者。他们要的是**准确、有出处、能拿来用**的信息，不是宣传稿。

## 1. 研究对象

研究对象是**公司（集团）**，不是单个品牌。子品牌、合资公司写在母公司的研究里。

## 2. 信息来源分级

| 级别 | 来源 | 能用来做什么 |
|---|---|---|
| A 一手 | 年报、半年报、招股书、交易所公告（港交所、上交所、深交所、纽交所）、公司官网和官方新闻稿、政府部门（工信部、发改委、国资委等）、乘联分会和中汽协发布 | 所有事实和**全部财务数据** |
| B 权威媒体 | 路透、彭博、金融时报、华尔街日报、日经、财新、第一财经、界面、21世纪经济报道、经济观察报、晚点 LatePost、CnEVPost、盖世汽车 | 历史事件、管理层变动、战略报道；必须写明是媒体报道 |
| C 其他 | 维基百科、百度百科、自媒体、论坛、汽车之家/懂车帝用户内容、LinkedIn | **只能当线索**，不能作为任何事实的唯一出处 |

- 财务数据只能用 A 级来源。非上市公司拿不到财务数据，就写「未公开披露」，不能估算。
- 同一事实不同来源说法冲突时，以 A 级为准；无法判断时写明分歧，并把两个来源都列出来。
- 每个来源要记：名称、链接（https）、发布日期、级别。

## 3. 章节结构（顺序固定）

1. **概览 overview**：两三句话说清这家公司是谁、靠什么赚钱、现在在行业里的位置。
2. **关键数据卡 key_facts**：成立年份、总部、所有制（国有/民营/混合）、实际控制人、上市地点和代码、员工数、最近一个财年的营收和净利润、最近一年的销量和海外销量。每一项都带期间和出处；没有就留 null。
3. **历史沿革 history**：时间线，8–20 个节点。写成立、关键转折、并购重组、上市、重大合作、重大挫折。每个节点：年份（能到月就到月）、事件、出处。
4. **现状 current**：业务结构（乘用车、商用车、电池、零部件等各占多少）、核心技术和平台、主要工厂和产能、国内市场地位、海外业务（主要市场、工厂、销量）。
5. **品牌矩阵 brands**：每个子品牌和合资公司一条——名称（中英）、定位、价格带、主力车型、创立年份、所属主体与持股、近年销量（有出处才写）。已停用或出售的品牌也列出，注明状态。
6. **创始人与管理层 leadership**：
   - 创始人：公开的职业经历和创业过程。
   - 现任核心管理层：董事长、CEO、总裁等，写职务、上任时间、此前公开履历。
   - 股权与治理：主要股东及持股比例（最近一期年报或公告）、实际控制人、董事会构成要点。
   - **只写公开的职务和商业信息**：不写家庭、健康、私人财富以外的私生活、传闻、派系；不写未经证实的负面说法。官方通报、法院判决可以写，写清它的实际结论。
7. **财务数据 financials**：近 3–5 个财年的表格。必填列：财年、营收、毛利率、净利润（归母）、研发投入；可选：经营现金流、现金及等价物、资产负债率、单车平均售价、汽车业务收入。
   - 写清币种、单位、会计准则（中国准则 / IFRS / US GAAP）和出处（哪一份年报）。
   - 不同口径不能混在一张表里。
   - 只写报表数字和简单比例，不做估值，不预测股价。
8. **竞争格局 competition**：主要对手、优势、短板。每个判断都要有事实依据。
9. **未来展望 outlook**：
   - 公司公开的目标和规划，引用原话或公告，带日期和出处。
   - 我们的分析：单独成段，写清依据、前提条件和其他可能。
10. **风险 risks**：经营、财务、政策、海外、技术路线等方面的主要风险，每条写依据。
11. **资料来源 sources**：全部来源的列表。

## 4. 写作规则

1. **只写有出处的事实。** 每段至少引一个来源；数字必须带期间、口径和出处。
2. **不编造。** 查不到就写「未公开披露」或留 null，不估算，不用「据悉」「业内人士称」。
3. **事实和推断分开。** 推断只能出现在「未来展望」的分析段和「竞争格局」里，要写明「我们的判断」及依据。
4. **不做投资建议。** 不写买入、卖出、目标价、评级、「值得投资」这类话。
5. **注意时效。** 每份研究写 `as_of`（研究截止日期）。描述「现在」的内容，以截止日期为准。
6. **中英双语。** 中文写给中文读者，英文写给海外读者，内容一致，不是机器直译。中文正文约 4000–8000 字，英文约 2500–5000 词。
7. **语气。** 冷静、具体、像行业研究报告，不用宣传用语（「遥遥领先」「颠覆」「王者」）。
8. **格式。** 正文 HTML 只能用 p h3 h4 strong em ul ol li blockquote table thead tbody tr th td a，链接只能写 `<a href="https://…">`，不带其他属性。不能用 script、style、img、iframe、注释。

## 5. 输出格式

一个 JSON 文件 `data/company-research/<id>.json`：

```json
{
  "id": "byd",
  "name_en": "BYD Company Limited",
  "name_zh": "比亚迪股份有限公司",
  "as_of": "2026-10-29",
  "ai_generated": true,
  "key_facts": [
    { "label_en": "Founded", "label_zh": "成立", "value_en": "1995", "value_zh": "1995 年", "period": null, "source_ids": ["s1"] }
  ],
  "history": [
    { "date": "2003-01", "event_en": "…", "event_zh": "…", "source_ids": ["s2"] }
  ],
  "brands": [
    { "name_en": "Denza", "name_zh": "腾势", "role_en": "…", "role_zh": "…", "price_band": "…", "founded": 2010, "owner_note_en": "…", "owner_note_zh": "…", "status": "active", "source_ids": ["s3"] }
  ],
  "financials": {
    "currency": "CNY", "unit": "million", "standard": "PRC GAAP",
    "rows": [ { "fiscal_year": 2025, "revenue": 0, "gross_margin_pct": 0, "net_profit": 0, "rnd": 0, "source_ids": ["s4"] } ],
    "note_en": "…", "note_zh": "…"
  },
  "sections": {
    "overview":    { "en": "<p>…</p>", "zh": "<p>…</p>" },
    "current":     { "en": "…", "zh": "…" },
    "leadership":  { "en": "…", "zh": "…" },
    "competition": { "en": "…", "zh": "…" },
    "outlook":     { "en": "…", "zh": "…" },
    "risks":       { "en": "…", "zh": "…" }
  },
  "sources": [
    { "id": "s1", "name": "BYD 2025 Annual Report", "url": "https://…", "date": "2026-03-25", "tier": "A" }
  ]
}
```

- 数值字段没有数据就写 null，不能写 0（真实为零除外）。
- `source_ids` 必须都能在 `sources` 里找到；正文里的链接也必须在 `sources` 里。
- 非上市、拿不到财务数据的公司：`financials.rows` 为空数组，`note` 写明原因。

## 6. 质检清单（审查时逐项检查）

1. JSON 能通过 `node scripts/check-research.js data/company-research/<id>.json`。
2. 关键数据卡和财务表的每个数字都能在所引的 A 级来源里找到，期间、单位、口径一致。
3. 历史时间线里的年份和事件，跟出处一致。
4. 子品牌的归属、持股比例与最新公告一致；已停用的品牌标明了状态。
5. 管理层只写了公开职务信息；没有私生活、传闻、派系、未经证实的负面说法。
6. 推断都写在规定的位置，并标明是判断。
7. 没有投资建议用语、没有宣传用语。
8. 中英文内容一致。
9. 没有只靠 C 级来源支撑的事实。

## 7. 更新

- 每年年报发布后（3–4 月）全面更新一次；半年报后更新财务表。
- 发生重大事件（并购、重组、管理层更换、退市、破产）时及时更新相关章节。
- 更新时改 `as_of`，旧版本留在 Git 历史里。
